### Pizza Menu

A menu for ordering a pizza. The user picks a size and any vegetable and meat toppings, then clicks **Place Order**. The app lists everything that was ordered and calculates the total price. The first topping is free, and each extra topping costs $1.

### Tic-Tac-Toe Game

The classic game of tic-tac-toe, played against the computer. The player is X, and the computer answers with an O in a random open square. Each move plays a sound. When someone gets three in a row, a line is drawn across the winning squares, a win sound plays, and the board resets. A tie has its own sound.

### Calculator

A basic four-function calculator. Users can add, subtract, multiply and divide, use decimals, and clear the screen with the **AC** button. It's laid out with CSS Grid to look like a real calculator.

### To-Do App

A simple to-do list. Users type a task and click **Add Item** to add it, and click the **x** next to a task to remove it. Tasks are saved in the browser's local storage, so they're still there after the page is refreshed or closed.

### jQuery

A page built with jQuery. It adds its content with `.append()`, colours text with `.css()`, hides the heading when a paragraph is clicked, brings it back on a double-click, and fades a paragraph in and out with `.fadeToggle()`.

### Basic JavaScript Projects

Ten smaller exercises covering the fundamentals:

1. **Expressions and alerts:** pop-up alerts, string concatenation and simple expressions
2. **Functions:** calling a function from a button and the `+=` operator
3. **Math operators:** addition, subtraction, multiplication, modulus, increment, decrement and random numbers
4. **Dictionaries:** key-value pairs and the `delete` statement
5. **Comparisons and type coercion:** `typeof`, `==` vs `===`, and logical operators
6. **Ternary operators and constructors:** a voting-age checker, object constructors with `this` and `new`, and nested functions
7. **Scope and time:** global vs local variables, `if/else` statements, and debugging with `console.log()`
8. **String methods:** `concat()`, `slice()`, `toString()` and `toPrecision()`
9. **Countdown and slideshow:** a countdown timer using `setTimeout()` and an image slideshow
10. **Loops and arrays:** `while` and `for` loops, arrays, and objects created with `let`
